  1. ক. সগীর আলী
  2. খ. কেষ্ট দাস ✓
  3. গ. মতলব মিয়া
  4. ঘ. রুস্তম শেখ

৪. ‘মোরা একটি ফুলকে বাঁচাবো বলে যুদ্ধ করি’–চরণটি তোমার পাঠ্যবইয়ের কোন কবিতার ভাবের সঙ্গে সাদৃশ্যপূর্ণ?

  1. ক. তোমাকে পাওয়ার জন্যে হে স্বাধীনতা ✓
  2. খ. স্বাধীনতা, এ শব্দটি কীভাবে আমাদের হলো
  3. গ. বঙ্গবাণী
  4. ঘ. জীবন-সঙ্গীত

সঠিক উত্তর: ক — তোমাকে পাওয়ার জন্যে হে স্বাধীনতা

সিলেট বোর্ড · ২০২৪

৫. ‘তোমাকে পাওয়ার জন্যে, হে স্বাধীনতা’ কবিতায় কার ফুসফুস এখন পোকার দখলে?

  1. ক. হরিদাসীর
  2. খ. মতলব মিয়ার
  3. গ. সগীর আলীর
  4. ঘ. রুস্তম শেখের ✓

সঠিক উত্তর: ঘ — রুস্তম শেখের

দিনাজপুর বোর্ড · ২০২৪

৬. ‘এই বলে মোর নাম খ্যাত হোক / আমি তোমাদেরই লোক।’ –পঙ্ক্তিটির ভাবের সাথে সাদৃশ্যপূর্ণ চরণ কোনটি?

  1. ক. আমি যে এসেছি জয়বাংলার বজ্রকণ্ঠ থেকে
  2. খ. সবাই অধীর আগ্রহে প্রতীক্ষা করছে তোমার জন্যে হে স্বাধীনতা
  3. গ. গণসূর্যের মঞ্চ কাঁপিয়ে কবি শোনালেন তার অমর কবিতাখানি
  4. ঘ. খোদার কসম আমি ভিনদেশি পথিক নই ✓

সঠিক উত্তর: ঘ — খোদার কসম আমি ভিনদেশি পথিক নই

দিনাজপুর বোর্ড · ২০২৪

৭. ‘তোমাকে পাওয়ার জন্যে, হে স্বাধীনতা’ কবিতায় সগীর আলী ছিলেন—

  1. ক. অকুতোভয় সৈনিক
  2. খ. শাহবাজপুরের জোয়ান কৃষক ✓
  3. গ. প্রবীণ জেলে
  4. ঘ. রিকশাওয়ালা

সঠিক উত্তর: খ — শাহবাজপুরের জোয়ান কৃষক
