৯. উদ্দীপক: int a = 5, b = 2; printf("%d", a / b); প্রোগ্রামটির আউটপুট কত?

  1. ক. 2.5
  2. খ. 2
  3. গ. 3
  4. ঘ. 1

সঠিক উত্তর: খ. 2

ব্যাখ্যা: a ও b দুটিই int, তাই ভাগফল পূর্ণসংখ্যা হয়; 5 / 2 = 2 (দশমিক অংশ বাদ যায়)।

১৪. উদ্দীপক: <h1 align="center">Welcome</h1> কোডটির আউটপুট কী হবে?

  1. ক. Welcome লেখাটি বড় হেডিং আকারে মাঝখানে দেখাবে
  2. খ. Welcome লেখাটি ছোট আকারে বামে দেখাবে
  3. গ. Welcome নামে একটি লিংক তৈরি হবে
  4. ঘ. কোনো আউটপুট দেখাবে না

সঠিক উত্তর: ক. Welcome লেখাটি বড় হেডিং আকারে মাঝখানে দেখাবে

ব্যাখ্যা: <h1> সবচেয়ে বড় হেডিং তৈরি করে এবং align="center" লেখাটিকে মাঝখানে বসায়।

  2. খ. %d
  3. গ. %s
  4. ঘ. %f

ব্যাখ্যা: %s স্ট্রিং, %c একটি অক্ষর, %d পূর্ণসংখ্যা এবং %f দশমিক সংখ্যার জন্য ব্যবহৃত হয়।

১৯. উদ্দীপক: int a = 8, b = 3; printf("%d", a % b); আউটপুট কত?

  1. ক. 3
  2. খ. 2
  3. গ. 5
  4. ঘ. 0

সঠিক উত্তর: খ. 2

ব্যাখ্যা: 8 ÷ 3 = 2 ভাগফল, ভাগশেষ 2। % অপারেটর ভাগশেষ দেয়।
