১. 3x + 7 ≤ 5x + 3 অসমতাটির সমাধান সেট কোনটি?

  1. ক. S = {x ∈ R : x ≥ 2}
  2. খ. S = {x ∈ R : x > 2}
  3. গ. S = {x ∈ R : x ≤ 2}
  4. ঘ. S = {x ∈ R : x ≥ −2}

সঠিক উত্তর: ক. S = {x ∈ R : x ≥ 2}

২. a(x + b) < c এবং a > 0 হলে, নিচের কোনটি সঠিক?

  1. ক. x > c/a + b
  2. খ. x < c/a − b
  3. গ. x < c/a + b
  4. ঘ. x > c/a − b

সঠিক উত্তর: খ. x < c/a − b

চট্টগ্রাম বোর্ড ২০২৪

৭. যদি x > y > 0 এবং z < 0 হয়, তবে নিচের কোনটি সঠিক?

  1. ক. x/z < y/z
  2. খ. x/z > y/z
  3. গ. z/x < y/z
  4. ঘ. x/z > z/y

সঠিক উত্তর: ক. x/z < y/z

চট্টগ্রাম বোর্ড ২০২৪

৮. উদ্দীপক: একটি গাড়ি ২ ঘণ্টায় x কি.মি. এবং ৩ ঘণ্টায় (x + ৬০) কি.মি. যায়। গাড়িটির গড় গতিবেগ অনূর্ধ্ব ৫০ কি.মি./ঘণ্টা। সমস্যাটির অসমতা রূপ নিচের কোনটি?

  1. ক. (x + x + 60)/2 ≤ 50
  2. খ. (2x + 3x + 60)/5 ≤ 50
  3. গ. (x + x + 60)/5 ≤ 50
  4. ঘ. (x + x + 60)/5 ≥ 50

সঠিক উত্তর: গ. (x + x + 60)/5 ≤ 50
